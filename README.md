## About this entry

The roast is aimed at one real behaviour, not at smart homes in
general. The fridge scans expiry dates and nags about them in
notifications, so the line turns it into a live-in nutritionist,
a health scold that moved into the kitchen uninvited. That is a
fresh angle: no milk-ordering joke, no robot uprising, just a small
domestic tyrant with a barcode scanner. The sting comes last, when
the nutritionist is caught living in my kitchen and paying no rent,
which reframes the nagging as a bad roommate instead of a feature.
The line is one sentence, it sets up fast, and it stays inside the
one hundred and sixty character cap. The program holds the line,
checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
